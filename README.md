# Genki

Genki 是一个面向患者的个人健康记录 iOS 应用原型，用来集中保存来自不同医院、体检机构和检查项目的资料。

数据当前使用 SwiftData 保存在设备本地。应用不会主动把病例、图片或 OCR 结果上传到服务器，也未启用 CloudKit 或 HealthKit 权限。

## 当前功能

- 记录就诊、体检、检查和其他健康资料
- 保存医院、日期、诊断或结论、检查结果、用药和医嘱等信息
- 使用系统文档扫描器扫描纸质资料
- 从照片中添加报告、胸片、眼底图等影像附件
- 使用 Apple Vision 在设备本地进行中英文 OCR
- 按医院、诊断、检查结果、药名及 OCR 原文搜索
- Debug 构建首次启动时提供三条本地演示记录
- 删除记录前需要确认；OCR 只填写空白字段，不会覆盖你手动填写或选择的内容
- 已定义版本化的记录导出格式，供日后的备份功能使用；暂不支持 iCloud 同步或写入系统健康数据

演示记录均为虚构内容；其中的胸片和眼底图为带有 C2PA 来源信息的 AI 生成示意素材，不对应任何真实患者，也不能用于医学判断。

## 运行要求

- macOS 与 Xcode 26.5 或更高版本
- iOS 26.5 或更高版本的模拟器或设备

## 开始运行

1. 使用 Xcode 打开 `Genki.xcodeproj`。
2. 选择一个 iPhone 模拟器或已连接设备。
3. 执行 **Product > Run**。

文档扫描依赖设备摄像头，在模拟器上可能不可用；照片导入和手动录入仍可正常测试。

## 隐私说明

这是早期原型。OCR 结果可能存在识别错误，重要医疗信息应与原始报告核对。本应用不提供诊断或医疗建议。

提交 Issue 或示例数据时，请勿上传真实患者姓名、病历号、报告图片或其他敏感医疗信息。
